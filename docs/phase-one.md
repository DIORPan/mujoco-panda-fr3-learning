# 第一阶段状态与后续计划

发布日期：2026-10-25。

## 当前完成范围

Panda：完成从规则专家采集到 CPU BC、闭合后策略状态专家补标、合并微调和冻结配对评估的完整流程。保存 20 对测试结果、便携权重及动作回放对比视频。保留原 BC 的失败作为对照。

FR3：使用 Menagerie FR3 与 Panda 双指夹爪，通过 MjSpec 运行时装配；完成抓取参考点、命名和控制站点适配。固定场景 3/3，种子 0～9 共 30/30 次抓放通过；未启用重力补偿。

## 当前限制

当前算力与时间有限，采用小型状态输入网络和 CPU 训练，先验证可复现的局部任务。尚未完成视觉输入、学习策略完整移动与放置、复杂物体、双臂协作或真机迁移。第一阶段样本规模较小，20/20 和 30/30 都只描述留存批次。

Panda 学习与 FR3 迁移使用独立的模型、控制实现和评价判据。FR3 迁移成功不代表 Panda 学习策略已迁移到 FR3。

## 后续更新方向

1. 在保持当前基线的前提下，分步增加抓取后的移动、到目标位置的下降和释放。
2. 分析失败并增加有针对性的状态覆盖，再考虑多轮专家补标；保留未见过的最终测试种子。
3. 扩展初始位置、物体参数和状态噪声，报告样本规模、失败类型与对照。
4. 条件允许后探索感知输入、学习策略跨模型迁移和双臂任务；这些属于计划，不计入当前成果。

当前模型、源文件哈希和正式结果作为冻结基线保留。修改任务或接口时创建新版本，不删除校验以套用旧指标。已测种子再次用于调试应标为回归检查。
