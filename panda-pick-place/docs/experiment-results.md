# 实验设置与结果

实验日期：2026-10-24。正式证据为 [paired_results.json](../experiments/2026-10-24/paired_results.json)，保留20对逐回合指标、模型和源文件哈希。

## 正式配对评估

种子3000–3019未用于本轮训练、验证或之前的失败诊断。两个冻结模型从相同的完整积分状态开始，执行器、动作限幅、固定朝向、环境和成功判据相同。

| 指标 | 原BC | 闭合后状态补标微调 |
|---|---:|---:|
| 成功回合 | 14/20 | 20/20 |
| 本批成功率 | 70% | 100% |
| 抬升后水平位移中位数 | 0.1615043119米 | 0.0017803524米 |

本批成功率相差30个百分点，水平位移中位数降低约98.90%。6个原失败种子为3001、3004、3008、3009、3011、3016，改进模型均成功；没有原成功而新失败的回合。

成功要求整个8秒任务完成，且最后0.5秒内：最小抬升至少0.10米、方块相对保持起点的最大位移不超过0.01米、方块到抓取点最大距离不超过0.04米。额外水平指标是首次达到0.10米抬升后到结束的最大XY位移，最终报告其20回合中位数。它不是最终放置误差。

## 数据与训练

- 40条规则专家轨迹，每条400组10状态/4动作样本，32条训练、8条验证：12800/3200组。
- 冻结原BC在另外40个位置运行，产生16000个状态，闭合后10624个状态获得专家标签。
- 补标按32/8回合划分：8460组训练标签、2164组验证标签；训练部分保留12条失败策略轨迹的有效标签。
- 合并训练21260组，分别保留两类验证共5364组。原BC训练100轮，最佳第97轮；微调100轮，最佳第98轮。
- CPU训练循环计时：原BC约10.3秒，微调约17.6秒。计时不包含所有进程启动、数据采集、安装与视频导出。
- Python 3.13.0、Torch 2.10.0+cpu、NumPy 2.2.6、MuJoCo 3.16.0。

## 失败诊断依据

原BC在另一批诊断种子2000–2019上为12/20；这与正式配对批的14/20属于不同位置集合，不能混作一次实验。诊断中的8个失败回合都曾抬高超过15厘米，问题集中在后续保持时的横向漂移和下降。

种子2002在微调前失败，微调后通过回归检查。专家同状态接管对照仅用于诊断恢复动作，不计入任何网络成功次数。正式结果全程由网络输出动作，没有专家接管。

部分原BC成功回合也存在较大中途横移，所以除末尾稳定判据外，同时报告抬升后的水平位移，避免只看成功率。

## 证据边界与来源

任务使用仿真真实状态、固定悬停起点、固定向下朝向和同一方块位置范围。结果不代表视觉端到端、完整放置、双臂协作、实机迁移、任意物体或任意工作空间的成功率。

预对齐6状态/2动作垂直抓取的20/20属于更早、更窄的任务。上游原项目12回合100%的规则控制结果见[上游README](upstream-readme.md)，不能算作学习扩展的实测数据。

本机原始证据位于Python项目的 runs/bc/reach_grasp_paired_eval_20261024T124012_277166Z/，不默认纳入版本控制。便携证据保留其JSON哈希，但省略本机绝对路径。便携权重与原模型逐参数相等；从头复现产生新的时间戳、数据路径和模型文件哈希。
