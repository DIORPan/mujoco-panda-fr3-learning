# 架构与接口

版本日期：2026-10-24。

## 数据流

规则专家轨迹 → 原BC监督训练 → 冻结原BC访问新状态 → 仅闭合后状态获得专家标签 → 与原示范合并微调 → 冻结两模型做新种子配对评估。

本实验是针对性的数据聚合与专家补标，采用 [DAgger](https://proceedings.mlr.press/v15/ross11a.html) 的策略访问状态补标思路。没有实现所有DAgger混合策略、轮次和基准设置，不将一次补标称为完整算法复现。

## 学习任务

准备阶段把机械臂移动到固定参考点[0.40, 0, 0.40]米，与方块位置无关。绿色方块初始X范围[0.43,0.55]米，Y范围[-0.08,0.08]米。任务为水平接近、下降、闭合、抬升并保持；参考朝向固定向下。

10维状态：

| 分量 | 维数 | 物理缩放 |
|---|---:|---:|
| 抓取点减方块的XYZ位置 | 3 | 各0.2米 |
| 方块相对初始高度的抬升 | 1 | 0.2米 |
| 双指平均位置 | 1 | 0.04米 |
| 上一拍夹爪打开指令 | 1 | 1 |
| 参考点减实际抓取点的XYZ误差 | 3 | 各0.02米 |
| 悬停高度减参考高度 | 1 | 0.2米 |

没有输入隐藏专家阶段或经过时间。位置来自MuJoCo状态，不是视觉检测结果。

网络为10→64 ReLU→64 ReLU→4，前三个输出经tanh变成归一化XYZ参考增量，末个输出经sigmoid后以0.5阈值决定开合。每轴每次最多2毫米，控制间隔20毫秒，包含10个2毫秒物理步。

IK把参考点与固定朝向转换成7个关节位置目标。关节目标在每个控制间隔内插值；夹爪使用模型原有执行器。两个策略共用同一执行器、工作空间边界与成功判据。

## 训练与补标

XYZ动作使用MSE，夹爪使用BCEWithLogits。原示范中的夹爪切换样本权重为50，并单独记录切换准确率；复制上一拍指令会掩盖漏闭合问题。

补标时每个动作仍由冻结原BC执行。仅在上一拍打开指令小于0.5的状态记录专家动作，专家标签不会执行。标签按相同参考点边界处理，记录为实际可执行的增量。失败运行的有效标签继续保留。

原专家轨迹与新补标轨迹分别以完整回合划分训练/验证，两个来源的训练集合并。微调从原BC最佳权重初始化，使用新的Adam优化器；选模指标是两类验证损失的等权均值。该损失不是闭环成功率。

## 可复现记录

- 原始轨迹：NPZ中的观测、动作、初始状态、元数据；JSON中的版本和SHA256。
- 补标轨迹：全程策略动作、选中的策略访问状态、专家标签及索引。
- 模型：CPU state_dict、物理缩放、数据划分、源文件哈希、训练配置。
- 配对评估：事先写入种子计划，每一对核对完整积分状态，保存两侧全部动作与结果。
- 便携冻结包：只复制原权重及必要的非本机元数据；逐参数核对相等。
- 视频：重放已测动作，逐步核对观测；额外渲染计算在独立MjData中执行。

环境不包含学习奖励或强化学习更新，也未接入真实机械臂、ROS 2或相机策略。
